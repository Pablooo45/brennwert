# Brennwert

Ernährungstracker als Web-App: Essen und Getränke per Freitext eintragen („2 Brötchen mit Nutella und ein Red Bull“),
Kalorien und Makros zusammenrechnen, Nährwerte nachschlagen. Läuft offline, alle Daten bleiben auf dem Gerät.

## Online stellen (GitHub Pages)
1. Alle Dateien in dieses Repository hochladen (liegen direkt im Hauptordner).
2. Settings → Pages → „Deploy from a branch“ → Branch `main`, Ordner `/ (root)` → Save.
3. Nach 1–2 Minuten ist die App unter `https://<benutzername>.github.io/<repo-name>/` erreichbar.

## Auf dem iPhone installieren
Link in **Safari** öffnen → Teilen-Symbol → „Zum Home-Bildschirm“ → Hinzufügen.

## Auf Android installieren
Link in **Chrome** öffnen → Menü (⋮) → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.
